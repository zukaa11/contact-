Here are the completed projects I have built and programmed using C++ and microcontrollers. Each one solves a real physical task.

PROJECT 01 // AUTONOMOUS ROBOT

Autonomous Line Following Robot

What it does: This is a small wheeled robot that drives by itself along a black line on the floor without any remote control or human driver.

How it works: It has 8 infrared sensors underneath looking at the floor. When the robot drifts slightly off-course, the sensors detect it instantly. My C++ code runs a mathematical balance formula (called PID) that adjusts the left and right wheel speeds hundreds of times per second so it steers back smoothly.

PROJECT 02 // HOME AUTOMATION

Smart Home Safety & Automation

What it does: A central electronic box that monitors home conditions like temperature, humidity, and dangerous smoke or gas leaks.

How it works: A dual-core ESP32 microcontroller continuously reads the sensors. If it detects smoke or gas above a safe level, it instantly triggers an alarm, automatically turns on an exhaust fan, and cuts off the electrical switch to keep the house safe.

PROJECT 03 // SECURITY ACCESS

RFID Smart Gates & Security Lock

What it does: A secure door or turnstile gate that only opens when someone taps an authorized security card or badge.

How it works: An RFID card reader scans the unique identification number inside the card wirelessly. The C++ code checks this number against a saved list of allowed keys in memory. If matched, it unlocks an electromagnetic latch and rotates a motor to open the gate.

RC522 RFID Module Electric Lock Latch Servo Motor Audible Buzzer

PROJECT 04 // AUTOMATED PARKING

Automated Parking Barrier System

What it does: A parking garage barrier that detects approaching cars, lifts the arm, and updates a screen showing how many parking spaces are left.

How it works: An ultrasonic sensor bounces sound waves off the front of a vehicle to measure distance. When the car stops close enough, the barrier arm lifts smoothly. Once the car passes through, the barrier lowers safely and decrements the open space counter.

Ultrasonic Sonar Servo Barrier Arm LCD Display Screen Safety Interlocks

PROJECT 05 // INFRASTRUCTURE

Synchronized Traffic Lights & Pedestrian Crosswalk

What it does: A fully coordinated traffic light system for a road intersection with pedestrian crossing signals.

How it works: Programmed with an organized state machine in C++. The green, yellow, and red lights cycle automatically without overlapping. When a pedestrian pushes the crosswalk button, the code recognizes the interrupt, safely turns the road yellow then red, and activates the green pedestrian walk signal.

C++ State Machine Pedestrian Button Interrupt Accident Prevention Logic
