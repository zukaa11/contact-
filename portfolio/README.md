Double-click [`launch.bat`](launch.bat) in this folder. It will instantly open the website in your default browser.

### Option 2: Direct Open
Double-click [`index.html`](index.html) to view the homepage, or [`inbox.html`](inbox.html) to check your messages.

## 🌐 Deploying to the Web (Free)

You can host this portfolio online in less than 2 minutes using **GitHub Pages**:
1. Push this folder to a GitHub repository.
2. Go to **Settings** > **Pages** in your repository.
3. Under **Branch**, select `main` and root `/`, then click **Save**.
4. Your website will be live at `https://<your-username>.github.io/<repo-name>/`.
